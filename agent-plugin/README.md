# Draw.AI agent plugin

The plugin that connects Claude Code and Codex to the **Draw.AI** extension for VS Code.
It ships inside the extension. Install it from VS Code with
**Draw.AI: Connect Claude Code / Codex…**, which copies it to `~/.drawio-ai/agent-plugin`
and registers it with each agent you choose.

What it contains:

- `skills/`: when and how to use the diagram tools. The same files are contributed to
  GitHub Copilot through the extension's `chatSkills`.
- `.mcp.json` and `bin/draw-ai-mcp`: a stdio MCP server, the agent bridge. It lists the
  `drawio_*` tools and forwards each call to the VS Code window that has the diagram. Every
  edit appears live in the Draw.AI editor, held for review.
- `.claude-plugin/` and `.codex-plugin/`: the manifests for Claude Code and Codex.

Everything stays on your machine. The bridge only talks to Draw.AI's MCP server on
`127.0.0.1`, which you turn on in VS Code.

The manifests and skills are generated by `scripts/generate-agent-plugin.js`; edit that
script, `src/features/ai/systemPrompt.ts` or `src/features/ai/toolSchemas.ts` instead.

Unofficial; not affiliated with draw.io or JGraph.
